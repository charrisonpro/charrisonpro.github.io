Technical Details

Claude Agents Architecture

Project Team

The development infrastructure consists of specialized agents:

  • Project Manager (PM): Strategy, task triage, decision-making
  • Prompt Engineer (PE): Agent design, framework maintenance
  • Project Coordinator (PC): Async queue processing, status tracking
  • Claude Code (Claudio): Implementation, file management, git

Specialist Agents

Each specialist extends a "personality stem" with domain-specific knowledge:

  • Coach Stem: Warmth, trust-building, pedagogical approach
  • Domain Knowledge: Regional dialect features, cultural context
  • Evaluation Framework: Hypotheses, test cases, feedback loops

Evaluation System

Each agent maintains testable hypotheses in the form:

P(outcome | condition) > threshold

Observations are collected and hypotheses updated as status transitions: untested → testing → supported/refuted.
